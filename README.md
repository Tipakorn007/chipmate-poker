# Chipmate — Poker Table UI (Texas Hold'em, ชิปสมมติ)

เว็บเกมโป๊กเกอร์ Texas Hold'em แบรนด์ **Chipmate** — เล่นกับบอทหรือสร้างห้องชวนเพื่อน
ใช้ **ชิปสมมติเท่านั้น** ไม่มีเงินจริง ไม่มีการเติมเงิน

React 18 + TypeScript + Vite · ธีม dark premium + ทอง · ฟอนต์ IBM Plex Sans Thai / Outfit

---

## เปิดโปรเจกต์ใน VS Code

```bash
# เปิดโฟลเดอร์นี้ใน VS Code
code .

# ติดตั้ง dependencies (ครั้งแรกครั้งเดียว)
bun install

# รัน dev server → http://127.0.0.1:5173
bun run dev
```

เปิด Terminal อีกหน้าต่างเพื่อรันเซิร์ฟเวอร์ห้องออนไลน์:

```bash
bun run server
```

จากนั้นเปิด `http://127.0.0.1:5173` สร้างห้อง และทดสอบลิงก์ในแท็บอื่น
ลิงก์ `127.0.0.1` ใช้ได้เฉพาะเครื่องเดียวกัน ไม่สามารถส่งให้เพื่อนต่างเครื่องใช้งานได้
โหมดบอทไม่ต้องเปิดเซิร์ฟเวอร์เกม

> Vite bind ที่ `127.0.0.1:5173`; เซิร์ฟเวอร์เกม bind ที่ `127.0.0.1:3001` โดยปริยาย

คำสั่งอื่น:

| คำสั่ง | ทำอะไร |
| --- | --- |
| `bun run dev` | dev server + hot reload |
| `bun run server` | เซิร์ฟเวอร์ห้องและเกมผ่าน WebSocket |
| `bun run build` | เช็ก type ของเว็บและเซิร์ฟเวอร์ แล้ว build เว็บไปที่ `dist/` |
| `bun run typecheck` | เช็ก type ของเว็บและเซิร์ฟเวอร์ |
| `bun test` | ทดสอบเกมและห้องออนไลน์ รวมจำลอง 10,000 มือเพื่อตรวจยอดชิป |
| `bun run preview` | เสิร์ฟไฟล์ที่ build แล้ว |

เซิร์ฟเวอร์เกมต้องใช้ Bun ส่วนเว็บ Vite สามารถ build ด้วย Node.js ได้

### ทดลองคิวอนิเมชัน

เปิด `http://127.0.0.1:5173/?demo` เพื่อดูตัวอย่างลำดับทั้งมือโดยไม่ต้องเปิดเซิร์ฟเวอร์เกม
ใช้ปุ่มเล่นซ้ำ ข้ามอนิเมชัน และช้าลง 0.5x หรือเลือกจังหวะผ่อนคลาย/เร็วได้
เดโมขั้นนี้แสดงลำดับคิวเท่านั้น ส่วนภาพไพ่ ชิป และการจ่ายจริงจะเพิ่มในขั้นถัดไป
ในโต๊ะจริง คิวภาพไม่หน่วงสถานะหรือคำสั่งเกม และหลังเชื่อมต่อกลับจะแสดงสถานะล่าสุด
การเปลี่ยนความเร็วมีผลกับเหตุการณ์ถัดไป; ค่าเวลาและ easing อยู่ใน `src/animation/constants.ts`

## ห้องออนไลน์

เจ้าของห้องกดคัดลอกหรือแชร์ลิงก์เชิญให้เพื่อนเปิด เลือกชื่อและอวตาร แล้วกดเข้าห้อง
หากได้รับเฉพาะรหัส 8 ตัว ให้เปิดเว็บแล้วกด **เข้าห้องด้วยรหัส** ที่ด้านบนของหน้าแรก
ปุ่มแชร์จะแสดงเมื่อเบราว์เซอร์รองรับ หากแชร์ไม่ได้ให้ใช้ปุ่มคัดลอกลิงก์หรือคัดลอกรหัสห้องส่งให้เพื่อนแทน
เกมเริ่มได้เมื่อมีผู้เล่นออนไลน์อย่างน้อย 2 คน
ผู้ที่เข้าระหว่างมือจะรอจนถึงมือถัดไป หากห้องเต็มจะมีข้อความแจ้ง
เซิร์ฟเวอร์เก็บสำรับและไพ่ที่ยังไม่เปิดไว้ฝั่งเซิร์ฟเวอร์ ตรวจตาและแอ็กชัน และส่งแชตให้สมาชิกในห้อง

หากมี all-in ที่เพิ่มไม่ถึงขนาด raise ขั้นต่ำ ผู้ที่เล่นไปแล้วเรียกหรือหมอบได้ แต่จะเพิ่มซ้ำไม่ได้
จนกว่ายอดที่เพิ่มจากครั้งล่าสุดที่ตนเล่นจะรวมกันถึงขนาด raise เต็ม

เดิมพันส่วนที่ไม่มีใครตามจะคืนให้เจ้าของก่อนแบ่งพอต แต่ละ side pot จ่ายให้เฉพาะผู้มีสิทธิ์
หากไม่มีผู้มีสิทธิ์ในพอตใด ระบบคืนเงินพอตนั้นตามส่วนที่แต่ละคนลง
เมื่อเสมอ เศษชิปของแต่ละพอตจะแจกตามลำดับที่นั่งทางซ้ายของปุ่มดีลเลอร์
ตามกติกาที่ตั้งไว้ในโปรเจกต์นี้ การกดหมอบเมื่อเช็กได้จะเปลี่ยนเป็นเช็กแทน
สำหรับการทดสอบ สามารถส่งฟังก์ชันสับไพ่ให้ `startHand` เพื่อจำลองผลซ้ำได้
หากไม่ส่ง ระบบยังสับด้วย `crypto.getRandomValues` ตามปกติ

หลังจบแต่ละมือจะแสดงผล 5 วินาทีแล้วเริ่มมือถัดไปอัตโนมัติเมื่อมีผู้เล่นที่มีชิปอย่างน้อย 2 คน
ผลมือจะแสดงชื่อผู้ชนะและชิปที่แต่ละคนได้รับบนโต๊ะโดยไม่เปิดหน้าต่างบังเกม
ผู้ที่เข้าระหว่างมือจะเข้าร่วมมือถัดไปโดยอัตโนมัติ บอทที่ชิปหมดจะไม่เติมชิปเอง
หากชิปของคุณหมด สามารถออกจากโต๊ะหรือเลือกเติมชิปตัวอย่างเองได้
ในห้องออนไลน์ผู้เล่นที่เหลือยังเล่นต่อได้ และผู้ที่ชิปหมดสามารถเติมชิปผ่านเมนูห้องเพื่อรอเข้ามือถัดไป

ระหว่างเล่นจะแสดงชุดไพ่ที่ดีที่สุดของคุณจากไพ่ในมือและไพ่กองกลางที่เปิดแล้ว
ไพ่เรืองแสงคือไพ่ที่ประกอบเป็นชุดนั้น (ไม่รวมไพ่คิกเกอร์สำหรับคู่ ตอง หรือโฟร์การ์ด)
เป็นข้อมูลเฉพาะมุมมองของคุณ ไม่ได้หมายความว่าจะชนะผู้เล่นคนอื่นเสมอไป
โต๊ะแสดงดีลเลอร์เพื่อประกอบการเล่น โดยไม่หน่วงสถานะเกม
ภาพแจกไพ่แบบเดิมถูกพักไว้ระหว่างเตรียมอนิเมชันใหม่ให้เล่นตามคิว
มุมมองโต๊ะวางผู้เล่นของคุณไว้ด้านล่าง แสดงที่นั่งว่างและผู้รอมือถัดไป
วงแหวนรอบอวตารระบุคนที่ถึงตาเท่านั้น ยังไม่ใช่นาฬิกานับถอยหลังจากเซิร์ฟเวอร์

เมื่อการเชื่อมต่อหลุด ระบบพยายามเชื่อมต่อใหม่และสำรองที่นั่ง 60 วินาที
หากถึงตาผู้เล่นที่หลุด ระบบจะเช็กเมื่อทำได้ มิฉะนั้นจะหมอบให้ หากเจ้าของห้องหลุด สิทธิ์จะโอนไปให้ผู้เล่นที่ยังออนไลน์
การรีเฟรชแท็บสามารถกลับเข้าห้องเดิมได้ภายในเวลาสำรองที่นั่งโดยกดปุ่มเข้าห้องอีกครั้ง

ห้องและชิปเก็บในหน่วยความจำของเซิร์ฟเวอร์เท่านั้น จึงหายเมื่อเซิร์ฟเวอร์รีสตาร์ต
ต้องรันเซิร์ฟเวอร์เพียงหนึ่ง instance; ยังไม่มีบัญชีผู้ใช้ ฐานข้อมูล หรือประวัติถาวร
อย่าใช้กับเงินจริงหรืองานที่ต้องการความปลอดภัยระดับ production

### เผยแพร่เพื่อเล่นต่างเครื่อง

1. สร้าง Web Service แบบ Docker บน Render จาก repository นี้ โดยใช้ `Dockerfile` ที่ root
2. ตั้ง environment variable `ALLOWED_ORIGINS` เป็น URL ของเว็บ Vercel ที่อนุญาต เช่น
   `https://chipmate-poker.vercel.app` (ไม่ต้องมี `/` ท้าย URL) หลาย URL คั่นด้วยจุลภาค
   ตั้ง health check path เป็น `/health` เซิร์ฟเวอร์ใช้พอร์ตจาก `PORT` ที่บริการกำหนด
3. ในโปรเจกต์ Vercel ตั้ง `VITE_POKER_SERVER_URL` เป็น URL ของ Render โดยใช้
   `wss://` และต่อท้าย `/ws` เช่น `wss://YOUR-SERVICE.onrender.com/ws`
4. Deploy เว็บ Vercel ใหม่หลังตั้งค่าตัวแปร แล้วใช้ลิงก์จากเว็บ Vercel เชิญเพื่อน

การตั้งค่า URL และการ deploy ต้องทำในบัญชี Render และ Vercel ของเจ้าของโปรเจกต์
หากบริการพักเครื่องหรือรีสตาร์ต ห้องที่กำลังเล่นจะหายไป
